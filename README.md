# 함께타 — 카쉐어링 · 카풀 플랫폼

카쉐어링(존 기반 10분 단위 대여)과 출퇴근 카풀을 한 앱에서 쓰는 모빌리티 서비스입니다.
현재 단계: **1단계 시뮬레이션** (`prototype/hamkketa-sim.html`, 브라우저 localStorage로 서버를 흉내 냄)

## 체험 계정
| 아이디 | 비밀번호 | 용도 |
|---|---|---|
| user1 | User!234 | 일반 회원 |
| admin | Admin!234 | 관리자 |
| newbie | Temp!234 | 첫 로그인(인증번호 → 비밀번호 변경), 카쉐어링 읽기 전용 |

## 주요 기능
- **카쉐어링**: 날짜·시간·이용 시간 선택 → 지도/목록에서 존 선택 → 차량별 예상 요금 → 면책 상품(라이트/스탠다드/슈퍼)·포인트 사용 → 예약 → 스마트키(문 열기/잠금/경적) → 반납 시 주행거리 요금 정산, 1% 포인트 적립. 취소 수수료(24시간 전 무료 / 1시간 전 10% / 이후 50%).
- **카풀**: 탑승 찾기(출발지·도착지 검색, 좌석 요청) / 운행 등록(평일 07–09시, 18–20시 출퇴근 시간만 허용) / 내 카풀(요청 수락·거절, 운행 완료·취소).
- **이용내역**, **내 정보**(운전면허 등록: 만 21세·취득 1년 이상 검사, 결제 카드, 비밀번호 변경)
- **관리자**: 회원 추가(임시 비밀번호 메일), 모듈별 읽기/쓰기 권한, 잠금 해제, 차량·존 관리, 운영 현황, 백업 목록·2단계 복원
- 공통: 한국어/스페인어 전환, 로그인 5회 실패 잠금, 30분 유휴 자동 로그아웃, 솔트+페퍼 반복 해시, 휴대폰 앱 바 + 메뉴판, 라이트/다크 모드
