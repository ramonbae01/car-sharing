# 함께타 — 카쉐어링 · 카풀 플랫폼

**엘살바도르**에서 쓰는 카쉐어링(존 기반 10분 단위 대여)과 카풀(비용 나눠 내기)을 한 앱에 담은 모빌리티 서비스입니다.
기본 언어는 스페인어이고 한국어로 바꿀 수 있습니다. 금액은 미국 달러(US$)입니다.
현재 단계: **1단계 시뮬레이션** (`prototype/hamkketa-sim.html`, 브라우저 localStorage로 서버를 흉내 냄)

## 주요 기능
- **카쉐어링**: 날짜·시간·이용 시간 선택 → 지도(Gran San Salvador 상세 / El Salvador 전국)·목록에서 존 선택 → 차량별 예상 요금 → 면책 상품(라이트/스탠다드/슈퍼)·포인트 사용 → 예약 → 스마트키(문 열기/잠금/경적) → 반납 시 주행거리 요금 정산, 1% 포인트 적립. 취소 수수료(24시간 전 무료 / 1시간 전 10% / 이후 50%).
- **카풀**: 탑승 찾기(출발지·도착지 검색, 좌석 요청) / 운행 등록(1인 $0.50~$30.00, 기름값·통행료 나누기) / 내 카풀(요청 수락·거절, 운행 완료·취소). 도시 간 이동(Santa Ana·San Miguel ↔ San Salvador) 예시 포함.
- **이용내역**, **내 정보**(운전면허 등록: 엘살바도르 면허=DUI 번호 00000000-0 또는 외국 면허, 만 21세·취득 1년 이상 검사, 결제 카드, 비밀번호 변경)
- **관리자**: 회원 추가(임시 비밀번호 메일), 모듈별 읽기/쓰기 권한, 잠금 해제, 차량·존 관리, 운영 현황, 백업 목록·2단계 복원
- 공통: 한국어/스페인어 전환, 로그인 5회 실패 잠금, 30분 유휴 자동 로그아웃, 솔트+페퍼 반복 해시, 휴대폰 앱 바 + 메뉴판, 라이트/다크 모드

## 엘살바도르 현지화 내용
- 대여 존 10곳: Centro Histórico, Metrocentro San Salvador, Zona Rosa, Multiplaza, Paseo El Carmen(Santa Tecla), Plaza Mundo Soyapango, Metrocentro Santa Ana, Metrocentro San Miguel, Playa El Tunco, 국제공항(SAL)
- 지역 표기: 옛 시 이름(현 distrito) · 2024년 개편 후 무니시피오 (예: `Soyapango · San Salvador Este`)
- 요금(예시, 센트 단위로 저장): 경차 $0.90/10분, 세단 $1.10, 전기차 $1.40, SUV $1.70, 픽업 $1.80 + km당 $0.08~$0.24
- 면책 상품: 자기부담금 최대 $1,000 / $500 / $100
- 차량 번호판 형식: `P 123-456`
