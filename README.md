# 함께타 (Hamkketa) — 엘살바도르 개인 간 차량 공유 · 카풀

**엘살바도르**에서 쓰는 개인 간(P2P) 렌터카 서비스입니다. 차주가 자기 차를 등록해 빌려주고, 인증을 마친 이용자가 그 차를 빌립니다. 카풀 기능도 함께 있습니다.
기본 언어는 스페인어이고 한국어로 바꿀 수 있습니다. 금액은 미국 달러(US$)이며, 소수점 오차를 막으려고 센트 단위 정수로 저장합니다.

현재 단계: **1단계 시뮬레이션** (`prototype/hamkketa-sim.html`)
- 서버 역할은 페이지 안의 `SRV` 객체가 하고, 데이터는 브라우저 localStorage에 저장합니다.
- `SRV` 객체는 나중에 `Code.gs`가 될 부분입니다.

## 흐름
### 빌려주는 사람 (내 차 빌려주기)
1. **차주 인증**: 운전면허증과 DUI 사진을 올립니다. AI가 검증하고, 둘 다 승인되어야 차를 등록할 수 있습니다.
2. **차 등록**: 아래 항목을 각각 따로 저장합니다.
   - ① 기본 정보·요금: 시간당 / 하루 최대 / km당
   - ② 차 사진: 카메라로 찍거나 앨범에서 고름. 최대 8장, 첫 장이 대표 사진
   - ③ 픽업 장소: 자주 쓰는 장소에서 고르거나 지도를 눌러 지정 + 상세 위치
   - ④ 빌려줄 수 있는 시간: 기간 추가, 빠른 입력(2주 평일 08~20시 / 4주 주말)
   - ⑤ 차량 서류: 차량 등록증(Tarjeta de Circulación), 보험증
3. 6개 항목이 모두 채워지고 서류가 승인되면 **게시하기** 버튼이 켜집니다.
4. 정산: 대여료와 주행요금의 **85%**를 차주가 받습니다.

### 빌리는 사람 (차 빌리기)
- 로그인이 필요합니다.
- 내 정보에서 **운전면허증·여권 사진 승인**과 **신용카드 등록**(Luhn 검사)을 마쳐야 예약할 수 있습니다.
- 날짜·시간·이용 시간을 고르면, 차주가 정한 가능 시간 안에 있고 다른 예약과 겹치지 않는 차만 보여 줍니다.
- 지도(수도권 / 전국)에는 시간당 요금이 표시됩니다.
- 결제 금액 = 대여료 + 보험 + **서비스 수수료 10%** − 포인트. 주행요금은 반납 후 따로 정산합니다.
- 차주를 픽업 장소에서 만나 차를 받고(차 인수 완료) → 반납합니다.

### AI 서류 검증
1. 사진을 올리면 Claude가 다음을 읽어 JSON으로 돌려줍니다.
   - 서류 종류, 이름, 번호, DUI, 생년월일, 발급일, 만료일, 번호판
   - 흐림 여부, 위·변조 흔적
2. 서버 규칙(`evalDoc`)이 그 결과로 판정합니다.
   - **승인**: 문제 없음
   - **관리자 확인**: 애매한 경우. 이름 불일치, 번호판 불일치, 등록증 소유자가 본인이 아님 등
   - **반려**: 명백한 문제. 다른 서류, 흐림, 위·변조, 만료, 만 21세 미만, 면허 취득 1년 미만
3. AI를 쓸 수 없으면 모든 서류가 관리자 심사(관리자 → 서류 심사)로 넘어갑니다.

## 실제 Apps Script로 옮길 때 바뀌는 점
- **서류·사진**: Drive 비공개 폴더에 저장합니다.
- **AI 검증**: 서버(`UrlFetchApp`)에서 Claude API를 호출합니다. API 키는 스크립트 속성에 둡니다.
- **카드**: 결제 대행사 토큰으로 처리합니다. 카드번호와 CVV는 저장하지 않습니다.
- **판정 규칙**: 시뮬레이션에서는 브라우저가 AI 결과를 서버로 넘깁니다. 실제로는 서버가 AI 호출부터 판정까지 모두 처리해야 조작을 막을 수 있습니다.
